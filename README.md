# Ebrahim Elmi - Personal Portfolio

A clean, professional portfolio website showcasing my background, projects, and contact information.

## Live Demo

[View Live Portfolio](https://ebrahimelmi.github.io/ebrahim-elmi-portfolio)

## 📋 Features

- **Responsive Design** - Works on all devices
- **Professional Layout** - Clean black and white theme
- **Interactive Elements** - Smooth hover effects and animations
- **Contact Integration** - Direct email, phone, and LinkedIn links
- **Resume Download** - PDF resume available for download
- **GitHub Integration** - Links to my GitHub profile

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- GitHub Pages (Hosting)

## 📁 Project Structure

```
portfolio/

├── contact.html        # Contact page
```
